For each team, average sentiment scores:

- Fall within a relatively narrow numerical band.
- Still show a **consistent positive correlation with team success metrics**.

Patterns observed:

- Teams that reached the playoffs generally display **higher average sentiment** and **higher win percentage**.
- Teams that missed the playoffs and posted poor records (e.g., **Athletics, Rockies, Nationals**) show **more negative sentiment**.
- Similar trends appear when sentiment is compared to **run differential**: higher run differential tends to align with more positive sentiment.

Regression analyses show that sentiment has **small but reliably positive coefficients** when predicting:

- Wins  
- Win percentage  
- Run differential  

Thus, **sentiment should not be treated as a standalone predictor of performance**, but it is a **directionally consistent indicator** of how well a team is doing.

**Core takeaway for the chatbot:**  
Sentiment can be used as a **supporting signal** that usually moves in the same direction as performance, but performance stats should remain the primary basis for evaluation.
